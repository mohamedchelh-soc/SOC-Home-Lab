# Security Scripts

## File Hash Checker

### Purpose

This Python tool calculates the SHA256 hash of a file.

It can be used during:
- Malware analysis
- Digital forensics investigations
- File integrity verification

### Usage

Run:

python file_hash_checker.py suspicious_file.exe
